# E9: Minimal Online Regime-Aware Dynamic Policy Switcher

## 1. Overview & Research Objective
Implements an online window detector switching between P1 and P2-tier based on batch anomaly rate and trust, resolving the static policy trade-off.

## 2. Master Configuration Anchor
All parameters, thresholds, and seeds used in this experiment are anchored in [`configs/paper.yaml`](../../configs/paper.yaml).

## 3. Execution & Verification
To reproduce this experiment independently:
```bash
bash run.sh
```
or directly via Python:
```bash
python ../../experiments/E9_regime_aware_switcher.py
python plot.py
```

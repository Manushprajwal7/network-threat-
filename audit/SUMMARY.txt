ROOT CAUSE OF TABLE 12 CORRUPTION
------------------------------------------------------------------------------
In train_ciciot2023_models.py (lines ~326-350), per-class precision, recall, and F1 are computed
with average='micro' on a subset of y_test masked to a single class. Since average='micro' on a
single-class subset always returns TP_c / support_c, the three metrics collapse to the same value
— per-class recall — and precision/recall/F1 are identical in every row of
per_class_metrics_ciciot2023.csv. Table 12 of the manuscript is derived from this corrupted file.
Table 15 was generated separately (via a correct classification_report() call) and is not affected.

DISCREPANCY SUMMARY AND LIKELY CAUSE (one paragraph)
------------------------------------------------------------------------------
The reviewer's observed gap between Table 12 (mean per-class F1) and Table 15 (Macro-F1) is real but
Table 15 is not the source of the error: for XGBoost, Random Forest, Decision Tree, and Naive Bayes,
Table 15's Macro-F1 values match genuine sklearn classification_report macro-avg F1 to 0.00 pp. The
reviewer's mean of Table 12, instead, matches true macro-RECALL almost exactly for all four models
(e.g. XGBoost 70.98% vs true macro-recall 70.98%), proving Table 12 was populated from a buggy script
that computes per-class recall and mislabels it as precision/recall/F1 alike. The reviewer's separate
suspicion that Decision Tree's Table 15 columns (Macro-F1 vs ADR) were transposed is not supported —
DT's true macro-F1 (66.23%) and true macro-recall/ADR (68.67%) are both independently correct and
merely close in value by coincidence.

CNN/LSTM PROVENANCE ISSUE
------------------------------------------------------------------------------
cnn_research.keras and lstm_research.keras were produced by train_research_models.py, which imports
from research_preprocess.py — a pipeline whose docstring states it is for CICIDS2017 and whose default
dataset directory is the CICIDS2017 folder. These two models cannot have produced 34-class CICIoT2023
metrics. The manuscript's CNN/LSTM rows in Table 15 and Table 15A must be removed or replaced with
CNN/LSTM models trained on CICIoT2023 with the same pipeline as the sklearn models.

Note: the paper's Table 15 reportedly includes CNN and LSTM rows, even though the Table 15 values given
for this audit listed only 7 sklearn models. This means the CNN/LSTM numbers currently in the manuscript
came from a source this audit cannot verify or locate in this codebase. Flagged for manual investigation.

MANUSCRIPT ERRORS DISCOVERED BEYOND THE REVIEWER'S FINDINGS
------------------------------------------------------------------------------
1. Table 15's Logistic Regression row does not correspond to any model in this codebase.
2. Table 15's KNN row shares Macro-F1, ADR, and FPR with the Naive Bayes row — a copy-paste
   error in the manuscript.
3. Table 15's SVM row appears to be the real Logistic Regression output.
4. Table 12's per-class F1 column is actually per-class recall due to the average='micro'
   bug on masked subsets.
These are more serious than the reviewer's two findings and must be disclosed in the revision.

SECTION 3 — Table 12 root cause
------------------------------------------------------------------------------------------
In train_ciciot2023_models.py (lines ~326-350), per-class precision, recall, and F1 are computed
with average='micro' on a subset of y_test masked to a single class. Since average='micro' on a
single-class subset always returns TP_c / support_c, the three metrics collapse to the same value
— per-class recall — and precision/recall/F1 are identical in every row of
per_class_metrics_ciciot2023.csv. Table 12 of the manuscript is derived from this corrupted file.
Table 15 was generated separately (via a correct classification_report() call) and is not affected.

SECTION 7 — Manuscript errors discovered beyond the reviewer's findings
------------------------------------------------------------------------------------------
1. Table 15's Logistic Regression row (81.61% acc / 47.70% macro-F1) does not correspond to
   any model's genuine output in this codebase. Real LR output: 0.15% acc / 0.50% macro-F1.
2. Table 15's KNN row (macro-F1 17.13%, ADR 22.08%, FPR 55.22%) is identical to the Naive Bayes
   row on those three metrics (only accuracy differs) — almost certainly a copy-paste error.
   Real KNN output: 0.75% acc / 0.20% macro-F1.
3. Table 15's SVM row (0.15% acc / 0.50% macro-F1) is numerically identical to the real
   Logistic Regression output — appears to be LR's output mislabeled as SVM.
   Real SVM output: 2.35% acc / 0.14% macro-F1.
4. Table 12's per-class F1 column is actually per-class recall, due to the average='micro'
   bug on masked single-class subsets (see Section 3).
These four issues are more serious than the reviewer's original two findings and should be
disclosed in the revision response letter.

SECTION 8 — CNN/LSTM provenance
------------------------------------------------------------------------------------------
cnn_research.keras and lstm_research.keras were produced by train_research_models.py, which
imports from research_preprocess.py — a pipeline whose docstring states it is for CICIDS2017
and whose default dataset directory is the CICIDS2017 folder. These two models cannot have
produced 34-class CICIoT2023 metrics. The manuscript's CNN/LSTM rows in Table 15 (and Table
15A, per the user) must be removed or replaced with CNN/LSTM models trained on CICIoT2023
using the same pipeline as the sklearn models. Their provenance in the current manuscript is
unverifiable from this codebase — CNN/LSTM are excluded from audit/Table_15_corrected.csv.
